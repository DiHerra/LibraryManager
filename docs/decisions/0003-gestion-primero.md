# ADR-0003: gestión primero, historia después

- Estado: aceptada (decisión de Diego, 2026-11-19)
- Alcance: orden del roadmap

## Contexto

Se valoraron tres enfoques: gestión profunda, gestión ligera con historia y gestión primero con historia después.

## Decisión

La 1.0 es el modo de gestión libre. El modo historia es un bloque posterior (L19) que reutiliza los sistemas de gestión ya probados, como hizo Volley Manager con su modo historia.

## Consecuencias

- Los sistemas de gestión se diseñan sin depender de un guion.
- Personajes, diálogos y retratos no bloquean la 1.0.
